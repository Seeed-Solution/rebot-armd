          抓取设置

          抓取任务

          选择 YOLO（或开启「识别」）后点画面里的框即可抓取。下面三项每次换桌面或相机支架后设置一次，保存在机械臂上。

          桌面高度--
          先把夹爪尖慢慢点动到刚好碰到桌面，再点上面的按钮。
          夹爪位置（画面）--
          夹爪朝下停在接近高度，张开，把物体放在桌面上两指正中间，然后点画面上物体的中心。
          --

          点位

          把机械臂移到想要的位置，起个名字记录下来；之后点「前往」机械臂会自己回到这个位置（需要先使能）。

          只能用英文字母、数字、下划线 _ 或短横线 -，最多 64 个字符；同名会覆盖。

              设置

              工具
              推荐顺序：零位标定 → 精校 → 夹爪标定。相机标定在不做精校时单独使用。
              碰撞保护
              机械臂运动中受阻时自动停在原地，受力消除后自动恢复；短时间内多次碰撞会锁定为故障。
              灵敏度
              高：轻微受阻就停；低：只在明显受阻时停。 注意：这台机械臂的碰撞阈值还没有标定，灵敏度只作试用参考；碰撞保护不能代替急停。
