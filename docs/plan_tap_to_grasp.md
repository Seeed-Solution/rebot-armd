# 计划：驾驶舱点框抓取（Tap-to-Grasp）

状态：计划，未实施（2026-11-09）。前置：视角模式遥操作（方案 A，`dev_flow_spec_view_frame_teleop.md`）先落地；本功能不依赖它的 6 轴 IK，可独立开发。

## 1. 范围

用户在驾驶舱开启「识别」→ 画面上的检测框可点击 → 点一个框 → 确认「抓取」→ 机械臂自动完成：俯视对准 → 下降 → 夹紧 → 抬起到安全高度保持。放置由用户手动遥操作完成。

不做：任意点击定位（点空白处移动）、拖拽、双指旋转、自动放置、高物体 / 叠放物体（第一版）。

## 2. 硬件前提与已知约束

- 单目 eye-in-hand：reCamera 装在 J6 之后，随 J6 转动（measurements）。
- 无深度。3D 位置的获取方式：
  - **水平 X/Y**：闭环视觉对中。每帧比较框中心与「夹爪位置像素」的偏差，按偏差小步移动 TCP，直到偏差 < 阈值。不需要精确内参与手眼标定，误差靠闭环收敛。
  - **高度 Z**：机械臂 FK 已知自身高度；桌面高度一次性测量；抓取高度 = 桌面 + 固定偏移（物体放在桌上）。
  - 后续（高物体）：下降过程中框尺寸 s₁→s₂，下降距离 Δh 由 FK 已知，Z₁ = Δh·s₂/(s₂−s₁)，不依赖内参。
- 检测：设备上的 yolo-detector（COCO 类别，只有框、无 mask、无 track id）。框无角度 → J6 只能取 0° / 90°（沿框短边夹）。
- 夹爪：J7，POS_VEL。armd 当前**没有**开机零位校验（`src/supervisor.rs` 只有 stall 检测）。

## 4. 交互设计（沿用现有驾驶舱样式）

1. 「识别」开启后，叠加层的框可点击（命中测试在 overlay 上做；不改现有绘制样式，选中框加高亮描边）。
2. 点框 → 视频区底部出现「抓取 / 取消」按钮组（现有 `.btn` 样式），显示类别与置信度。
3. 抓取中：显示当前阶段（对准 / 下降 / 夹紧 / 抬起）与进度；「停止」按钮常驻。
4. 任一中止条件 → 停在当前位置（保持力矩），提示原因：
   - 用户操作任意摇杆 / 按键 / 点停止 / 急停；
   - 目标连续丢失 > 1 s；
   - 单阶段超时；
   - IK / 限位 / 地面 / 滞后保护触发（复用 `cartTick` 现有保护）。
5. 抽屉新增「抓取设置」：桌面高度（让臂慢降触桌或手动输入）、夹爪位置像素（物体放在张开的夹爪之间，点一下画面记录）、抓取偏移、速度。

## 5. 实施步骤

0. **夹爪零位校验（armd，安全前置）**：开机或首次使能时，夹爪低速闭合直到堵转，确认堵转位置在 0 ± 0.15 rad 内；否则锁存故障、禁止张开超过安全值。先在真机读一次上电后的 J7 位置，确认是否存在偏移问题。
1. **框可点击**：overlay 命中测试、选中状态、跨帧跟踪（类别相同 + IoU / 中心距门限，取多帧中位数）。
2. **抓取状态机（浏览器侧）**：通过 `C.goal` 驱动现有笛卡尔通道（限速、跳变、滞后、地面保护、租约看门狗全部保留）。
   - a. 张开夹爪到 min(框宽估计 + 余量, 9 cm)；
   - b. 移到目标上方、俯视（pitch = 90°），高度 = 桌面 + 安全高度；
   - c. 对中：按像素偏差小步移动 X/Y，直到偏差 < 阈值并稳定 N 帧；J6 转到框短边方向（0° / 90°）；
   - d. 下降到抓取高度，下降中持续对中，直到框超出画面或尺寸超过阈值后停止对中、盲降剩余距离；
   - e. 夹紧，按 §3 的夹持判定；闭空 → 张开、抬起、提示「未抓到」，可重试一次；
   - f. 抬起到安全高度保持，交还用户控制。
3. **抓取设置与持久化**：桌面高度、夹爪像素、偏移存 localStorage（与标定模式同样的方式）。
4. **i18n**：中英文全部新文案。
5. **测试**：
   - 自测脚本：假检测序列驱动状态机（对中收敛、丢失中止、闭空重试、超时）；
   - 真机：杯子 / 瓶子等 COCO 类物体，记录成功率、对中残差、单次耗时。

## 6. 待真机确认

- 夹爪最大开口与 J7 角度的对应关系（未测）。

- J7 上电零位是否偏移（步骤 0）。
